
## Problem: Reverse String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach
I used the two-pointer technique. One pointer starts at the beginning and the other at the end. I swap the characters and move both pointers towards the centre until the string is reversed.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
The solution reverses the character array in place without using an additional array.

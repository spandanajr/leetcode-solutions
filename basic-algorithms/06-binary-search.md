
## Problem: Binary Search (Easy)

**Link:** https://leetcode.com/problems/binary-search/

### Approach
I used the binary search technique on a sorted array. I repeatedly calculate the middle index and compare its value with the target. I reduce the search range until the target is found or the range becomes empty.

### Complexity
- Time: O(log n)
- Space: O(1)

### Notes
Binary search works only when the input array is sorted.
